# Configuración de geolocalización

Esta pantalla permite crear y administrar puntos de geolocalización para el registro de asistencia.

> **Nota**
>
> Esta funcionalidad aplica únicamente cuando la empresa utiliza la opción de checador web o checador móvil.

## ¿Para qué sirve?

Sirve para definir geocercas o puntos autorizados desde donde los empleados pueden realizar sus marcajes.

Estos puntos pueden asignarse al personal para controlar que los registros de asistencia se realicen dentro de las ubicaciones permitidas.

## ¿Cómo se utiliza?

Crea un punto de geolocalización indicando su nombre, ubicación en el mapa y distancia permitida.

Después, asigna los empleados que podrán utilizar ese punto para realizar sus marcajes desde web o celular.

## Acciones disponibles

Desde esta pantalla puedes crear, consultar, editar o eliminar puntos de geolocalización.

También puedes asignar o desasignar empleados a cada punto configurado.

## Consideraciones

Es recomendable validar la ubicación y distancia permitida antes de asignar empleados.

Una configuración incorrecta puede impedir que el empleado registre su asistencia desde el checador web o móvil.
