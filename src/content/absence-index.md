# Tipos de falta

Esta pantalla permite administrar el catálogo de tipos de ausentismo utilizados en la organización.

> **Nota**
>
> Cada tipo de falta debe tener asignado un subtipo, ya que este ayuda a clasificarlo correctamente dentro de las opciones y procesos del sistema.

## ¿Para qué sirve?

Sirve para definir los distintos tipos de ausencias que podrán registrarse o generarse dentro de ORIANNA.

Estos tipos pueden utilizarse en procesos como permisos, incapacidades, faltas, vacaciones u otros movimientos relacionados con asistencia.

## ¿Cómo se utiliza?

Selecciona el botón **Agregar** para crear un nuevo tipo de falta.

Captura la información correspondiente, como clave, descripción y subtipo relacionado.

## Acciones disponibles

Desde esta pantalla puedes crear, consultar, editar o eliminar tipos de falta.

## Consideraciones

Es recomendable validar que el subtipo asignado corresponda al uso real del ausentismo dentro de la operación.

Una configuración incorrecta puede afectar la clasificación de ausencias, incidencias o reportes relacionados con T&A.
