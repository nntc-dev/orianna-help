# Cambio masivo de rol de turnos

Esta pantalla permite cambiar de forma masiva el rol de turnos asignado al personal.

> **Nota**
>
> Los cambios aplicados se reflejarán en el expediente del empleado dentro de ORIANNA.

## ¿Para qué sirve?

Sirve para actualizar el rol de turnos de varios empleados al mismo tiempo, evitando realizar el cambio de manera individual por empleado.

## ¿Cómo se utiliza?

Selecciona los criterios de búsqueda, como grupo de empleados, ubicación, área u otros filtros disponibles.

La pantalla mostrará una vista previa con el personal seleccionado, indicando el rol anterior y el rol nuevo que será asignado.

Una vez validada la información, aplica el cambio para actualizar el rol de turnos de los empleados seleccionados.

## Acciones disponibles

Desde esta pantalla puedes generar una nueva carga de cambio masivo, revisar el previo de empleados afectados y aplicar los cambios de rol de turnos.

## Consideraciones

Es recomendable validar cuidadosamente el listado previo antes de aplicar el cambio.

Una vez aplicado, el nuevo rol puede impactar la programación de turnos, asistencia, incidencias, retardos, faltas u horas extra, dependiendo de las reglas configuradas para la empresa.
