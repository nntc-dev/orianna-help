# Biométricos

Esta pantalla permite administrar el catálogo de relojes biométricos utilizados por la organización.

> **Nota**
>
> La correcta configuración de los biométricos es importante para la obtención de marcajes y su integración con ORIANNA.

## ¿Para qué sirve?

Sirve para registrar los dispositivos físicos desde los cuales se obtienen los marcajes de entrada, salida, comida u otros eventos configurados.

Cada biométrico puede incluir información como nombre, IP, número de serie, tipo de dispositivo, ubicación y datos necesarios para su conexión.

## ¿Cómo se utiliza?

Selecciona el botón **Agregar** para registrar un nuevo biométrico.

Captura la información correspondiente del dispositivo y valida que los datos de conexión sean correctos.

## Acciones disponibles

Desde esta pantalla puedes crear, consultar, editar o eliminar biométricos.

## Consideraciones

Una configuración incorrecta puede afectar la lectura de marcajes o la comunicación con los dispositivos físicos.

Es recomendable validar la IP, número de serie, tipo de biométrico y ubicación antes de guardar la configuración.
