# Importar registros de comida

Esta pantalla permite importar registros de comedor mediante layout.

> **Nota**
>
> Esta opción se utiliza para cargar registros de comida que no fueron capturados desde el biométrico o dispositivo correspondiente.

## ¿Para qué sirve?

Sirve para registrar consumos de comedor de manera manual o masiva, cuando por alguna situación no se cuenta con el marcaje original del dispositivo.

Estos registros pueden utilizarse posteriormente para generar el descuento de comida correspondiente.

## ¿Cómo se utiliza?

Carga el layout con los registros de comida que deseas importar.

El sistema realizará las validaciones correspondientes y mostrará los registros con errores, en caso de existir.

Una vez validada la información, los registros podrán aplicarse para que sean considerados dentro del proceso correspondiente.

## Acciones disponibles

Desde esta pantalla puedes importar registros, revisar errores de validación, aplicar los registros correctos y exportar la información a **Excel**.

## Consideraciones

Es recomendable revisar los errores antes de aplicar la carga, para evitar registros incompletos o incorrectos.

Los registros aplicados pueden impactar el cálculo de descuentos de comedor, dependiendo de las reglas configuradas para la empresa.
