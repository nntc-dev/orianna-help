# Avisos - Portal

Esta pantalla permite consultar los **avisos** publicados para el empleado, revisar su contenido y, cuando corresponda, confirmar que fueron vistos.

## ¿Para qué sirve?

La pantalla de **Avisos - Portal** permite consultar la información publicada mediante avisos y atender aquellos que requieren confirmación.

Desde esta pantalla es posible:

* Consultar los avisos disponibles.
* Identificar los avisos que requieren confirmación.
* Confirmar que un aviso fue visto.
* Consultar el contenido de los avisos.
* Consultar los archivos asociados a un aviso.
* Visualizar imágenes y archivos PDF asociados a un aviso.

## ¿Cómo se utiliza?

Al ingresar al portal se muestran los avisos disponibles para el empleado.

Cada aviso puede contener:

* **Título:** nombre del aviso.
* **Contenido:** información publicada en el aviso.
* **Fecha de inicio:** fecha a partir de la cual se encuentra disponible.
* **Fecha de vigencia:** fecha hasta la cual aplica el aviso, cuando se haya establecido.
* **Color:** permite identificar visualmente el aviso.
* **Anclado:** indica que el aviso se encuentra destacado.
* **Necesita confirmación:** indica que el aviso requiere que el empleado confirme que fue visto.

Los avisos pueden estar dirigidos a determinados grupos de empleados mediante su **Razón social**, **Ubicación** o **Departamento**.

## Acciones disponibles

### Consultar un aviso

Para consultar un aviso:

1. Localiza el aviso que deseas revisar.
2. Consulta el **Título** y el **Contenido**.
3. Revisa la información y las fechas asociadas al aviso.
4. Si el aviso contiene archivos, consulta los archivos disponibles.

### Confirmar un aviso

Cuando un aviso requiere confirmación:

1. Selecciona la opción para confirmar el aviso.
2. Revisa el mensaje de confirmación.
3. Selecciona **Aceptar**.

Al confirmar, el aviso queda registrado como visto.

### Consultar archivos

Los avisos pueden tener archivos asociados.

Los archivos se identifican mediante un ícono de acuerdo con su tipo, por ejemplo:

* Imágenes.
* Excel.
* Word.
* PowerPoint.
* PDF.
* Otros archivos.

Los archivos PDF pueden visualizarse directamente dentro del portal y las imágenes pueden mostrarse dentro de un visor.

### Administrar archivos de un aviso

Al agregar archivos a un aviso:

1. Selecciona la opción para agregar un archivo.
2. Selecciona uno o varios archivos.
3. Revisa los archivos agregados.
4. Elimina de la lista aquellos que no deseas asociar.
5. Selecciona **Guardar**.

Cada archivo agregado no debe superar **1 MB**.

Para eliminar un archivo que ya está asociado a un aviso:

1. Selecciona el botón **Eliminar** correspondiente al archivo.
2. Revisa el mensaje de confirmación.
3. Selecciona **Aceptar**.

### Configurar la estructura a la que aplica un aviso

Un aviso puede asociarse a diferentes elementos de la estructura organizacional.

Para configurar la estructura:

1. Selecciona el **Tipo de estructura**.
2. Selecciona los elementos correspondientes.
3. Selecciona **Guardar**.

Los tipos de estructura disponibles son:

* **Razón social**
* **Ubicación**
* **Departamento**

Para eliminar una estructura asociada:

1. Selecciona el botón **Eliminar** correspondiente.
2. Revisa el elemento que se eliminará.
3. Selecciona **Aceptar**.

## Consideraciones

Los avisos pueden requerir confirmación por parte del empleado.

Los archivos asociados a los avisos tienen un límite de **1 MB por archivo**.

La información que se muestra al empleado depende de la estructura organizacional a la que se haya asociado el aviso.
