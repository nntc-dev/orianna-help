# Empresas

Esta pantalla permite visualizar el catálogo de empresas.

> **Nota**
>
> La empresa es el elemento base sobre el que se estructuran las razones sociales, ubicaciones, departamentos y demás catálogos organizacionales dentro de ORIANNA.

## ¿Para qué sirve?

Sirve para poder visualizar la empresa en la cual se esta operando desde ORIANNA.
