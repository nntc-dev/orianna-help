# Layout nómina

Esta pantalla permite generar un **layout de nómina** en formato **Excel**, utilizando información de incidencias de los empleados de acuerdo con los filtros seleccionados.

> **Nota**
>
> El archivo generado contiene la información correspondiente a los criterios de búsqueda seleccionados. Antes de generar el layout, es recomendable validar las fechas y los filtros utilizados.

## ¿Para qué sirve?

Sirve para obtener en un archivo de **Excel** la información necesaria para trabajar con el layout de nómina.

La información puede consultarse considerando diferentes criterios, como:

* Rango de fechas.
* Empleado.
* Incidencia.
* Razón social.
* Ubicación.
* Departamento.
* Estatus de la incidencia.
* Periodo de pago.

Esto permite generar un archivo con información específica de acuerdo con las necesidades de consulta o del proceso de nómina.

## ¿Cómo se utiliza?

Al ingresar a la pantalla se muestran los filtros disponibles para definir la información que se incluirá en el layout.

Captura o selecciona los criterios que deseas utilizar:

**Fecha inicial:** indica la fecha desde la cual se desea consultar la información.

**Fecha final:** indica la fecha hasta la cual se desea consultar la información.

**Empleado:** permite seleccionar un empleado específico para generar el layout únicamente con su información.

**Incidencia:** permite seleccionar el tipo de incidencia que se desea considerar.

**Razón social:** permite seleccionar la razón social a la que pertenecen los registros que se desean consultar.

**Ubicación:** permite seleccionar una ubicación específica.

**Departamento:** permite seleccionar un departamento específico.

**Estatus de la incidencia:** permite seleccionar el estatus de las incidencias que se desean incluir.

**Periodo:** permite seleccionar el periodo de nómina correspondiente.

Los filtros de **Empleado**, **Incidencia**, **Razón social**, **Ubicación**, **Departamento**, **Estatus de la incidencia** y **Periodo** permiten buscar y seleccionar una opción desde su lista correspondiente.

Una vez definidos los filtros, selecciona el botón **Layout** con el ícono de Excel para generar el archivo.

El sistema abrirá una nueva ventana con el archivo de Excel generado.

## Acciones disponibles

### Generar layout

Permite generar el archivo de **Excel** utilizando los filtros seleccionados.

Antes de generar el archivo, revisa que el rango de fechas y los demás criterios correspondan a la información que necesitas incluir.

### Consultar por empleado

Permite seleccionar un empleado específico para generar el layout únicamente con la información relacionada con ese empleado.

### Filtrar por incidencia

Permite seleccionar una incidencia específica para limitar la información incluida en el layout.

### Filtrar por estructura organizacional

Puedes utilizar los filtros de **Razón social**, **Ubicación** y **Departamento** para limitar la información a una parte específica de la estructura de la empresa.

### Filtrar por estatus de incidencia

Permite seleccionar el estatus de las incidencias que serán consideradas para la generación del layout.

### Filtrar por periodo

Permite seleccionar un periodo de nómina para generar la información correspondiente al periodo seleccionado.

## Consideraciones

El rango de fechas determina el periodo de información que se utilizará para generar el layout.

Si no se especifica una fecha inicial o final, el sistema utiliza un rango predeterminado para realizar la consulta.

De igual forma, los filtros que no sean seleccionados se consideran sin una restricción específica, por lo que la información puede incluir todos los registros disponibles que correspondan a los demás criterios.

Es recomendable revisar especialmente las **fechas**, el **periodo**, el **estatus de la incidencia** y los filtros de estructura organizacional antes de generar el archivo.

El layout se genera en formato **Excel** y se abre en una nueva ventana del navegador.
