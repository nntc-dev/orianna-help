# Grupos de empleados

Esta pantalla permite crear y administrar grupos de empleados dentro de ORIANNA.

> **Nota**
>
> Actualmente, los grupos de empleados se utilizan principalmente para procesos de cambio masivo de roles de turno.

## ¿Para qué sirve?

Sirve para agrupar empleados y facilitar procesos masivos donde se requiere trabajar con un conjunto específico de personal.

Los grupos pueden armarse utilizando filtros como ubicación, departamento, razón social u otros criterios disponibles.

## ¿Cómo se utiliza?

Selecciona el botón **Agregar** para crear un nuevo grupo.

Después, agrega los empleados que formarán parte del grupo. La pantalla permite consultar los empleados asignados y eliminar integrantes cuando sea necesario.

## Acciones disponibles

Desde esta pantalla puedes crear, consultar, editar o eliminar grupos de empleados.

También puedes asignar o quitar empleados de un grupo y exportar la información a **Excel**.

## Consideraciones

Es recomendable mantener actualizados los grupos para que los procesos masivos se apliquen únicamente al personal correcto.

Una configuración incorrecta puede afectar procesos como el cambio masivo de roles de turno.
