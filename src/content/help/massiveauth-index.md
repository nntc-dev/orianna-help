# Autorización masiva

Esta pantalla permite autorizar incidencias de forma masiva, de acuerdo con los filtros seleccionados.

> **Nota**
>
> Esta opción está dirigida a usuarios de nivel superior, como gerentes o autorizadores de nivel 2.

## ¿Para qué sirve?

Sirve para autorizar varias incidencias al mismo tiempo, evitando revisar cada registro de forma individual.

Desde esta pantalla se pueden consultar incidencias creadas o pendientes de autorización del nivel inferior al usuario que está realizando el proceso.

## ¿Cómo se utiliza?

Utiliza los filtros disponibles para consultar las incidencias que deseas revisar.

Antes de autorizar, valida que los registros mostrados correspondan al periodo, empleado, supervisor, ubicación o tipo de incidencia correcto.

Para autorizar las incidencias mostradas, selecciona la opción de **Autorizar**.

## Acciones disponibles

Desde esta pantalla puedes consultar incidencias, revisar su estatus, exportar la información a **Excel** y autorizar registros de forma masiva.

## Consideraciones

La autorización masiva aplica sobre las incidencias que cumplan con los filtros seleccionados y que el usuario tenga permitido autorizar.

Es recomendable revisar la información antes de confirmar el proceso, ya que las incidencias autorizadas pueden continuar hacia integración con nómina o reportes administrativos.
