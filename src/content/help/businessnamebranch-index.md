# Razón social

Esta pantalla permite administrar el catálogo de razónes sociales dentro de la empresa.

## ¿Para qué sirve?

Sirve para registrar las diferentes razones sociales que forman parte de la organización.

Esta información permite ubicar y organizar empleados, turnos y demás elementos operativos según la razón social a la que correspondan.

## ¿Cómo se utiliza?

Selecciona el botón **Agregar** para agregar una nueva razón social.

Captura la información correspondiente, como nombre, datos correspondientes a la dirección, dirección, RFC y correo electronico.

## Acciones disponibles

Desde esta pantalla puedes crear, consultar, editar o eliminar las razones sociales que pertenecientes a la empresa.
