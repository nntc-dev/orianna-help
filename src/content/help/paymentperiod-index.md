# Periodos

Esta pantalla permite administrar los **periodos de nómina** utilizados en los procesos de **Nómina**.

> **Nota**
>
> La correcta configuración de los periodos y sus fechas es importante para mantener la operación de los procesos de nómina.

## ¿Para qué sirve?

Sirve para crear y administrar los periodos de nómina, así como las fechas asociadas a cada periodo.

También permite establecer las fechas de bloqueo correspondientes al tipo de periodo.

## ¿Cómo se utiliza?

Selecciona el botón **Agregar** para crear un nuevo periodo.

Una vez creado, podrás consultar y modificar su información, así como administrar las fechas correspondientes al periodo seleccionado.

Para establecer fechas de bloqueo, selecciona la opción **Bloquear periodos** y configura el tipo de periodo y las fechas correspondientes.

## Acciones disponibles

Desde esta pantalla puedes crear, modificar y eliminar periodos.

También puedes agregar, modificar y eliminar las fechas asociadas a cada periodo y establecer las fechas de bloqueo para los tipos de periodo disponibles.

## Consideraciones

Es recomendable validar que las fechas inicial y final de cada periodo sean correctas antes de utilizarlas en los procesos de nómina.

Las fechas de bloqueo deben configurarse de acuerdo con la operación y los periodos definidos por la empresa.
