# Faltas injustificadas

Esta pantalla permite capturar y consultar faltas injustificadas de los empleados.

> **Nota**
>
> Las faltas injustificadas se registran cuando el empleado no asistió y no cuenta con una justificación válida para cubrir la ausencia.

## ¿Para qué sirve?

Sirve para registrar ausencias no justificadas de manera individual, ya sea por un solo día o por un rango de fechas.

## ¿Cómo se utiliza?

Utiliza los filtros disponibles para consultar las faltas registradas por departamento, ubicación o rango de fechas.

Para capturar una nueva falta injustificada, selecciona el botón **Agregar** y registra la información correspondiente del empleado, fecha o rango de fechas y motivo.

## Acciones disponibles

Desde esta pantalla puedes agregar, editar o eliminar faltas injustificadas existentes.

También puedes exportar la información consultada a **Excel** para revisión o respaldo.

## Consideraciones

Las faltas injustificadas pueden impactar el cálculo de asistencia, incidencias, descuentos o reportes de nómina, dependiendo de las reglas configuradas para la empresa.

Es recomendable validar previamente que no exista un permiso, incapacidad, vacaciones u otra justificación registrada para el mismo periodo.
