# Festivos

Esta pantalla permite administrar el catálogo de días festivos reconocidos por la empresa.

> **Nota**
>
> La correcta configuración de los días festivos es importante para el cálculo de asistencia e incidencias.

## ¿Para qué sirve?

Sirve para registrar los días festivos que serán considerados dentro de los procesos de Tiempo y Asistencia.

Estos días pueden utilizarse para identificar festivos trabajados, evitar la generación incorrecta de faltas o aplicar reglas especiales configuradas para la empresa.

## ¿Cómo se utiliza?

Selecciona el botón **Agregar** para registrar un nuevo día festivo.

Captura la información correspondiente, como nombre del festivo, fecha y estatus activo.

## Acciones disponibles

Desde esta pantalla puedes crear, consultar, editar o eliminar días festivos.

## Consideraciones

Una configuración incorrecta puede afectar el cálculo de faltas, incidencias, días festivos trabajados o reportes relacionados con asistencia.

Es recomendable revisar y actualizar este catálogo antes del inicio de cada año o periodo operativo.
