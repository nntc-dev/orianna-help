# Datos extraordinarios

Esta pantalla permite administrar datos adicionales que pueden registrarse para los empleados y definir la forma en que se capturan.

## ¿Para qué sirve?

La pantalla de **Datos extraordinarios** permite configurar información adicional para los empleados que no forma parte de los datos generales del empleado.

Desde esta pantalla es posible:

* Consultar los datos extraordinarios configurados.
* Agregar un nuevo dato extraordinario.
* Definir el tipo de captura del dato.
* Configurar características adicionales de los datos.
* Configurar opciones personalizadas para datos de selección.
* Editar un dato extraordinario.
* Eliminar un dato extraordinario.

## ¿Cómo se utiliza?

Al ingresar a la pantalla se muestran los datos extraordinarios organizados por sección.

Cada dato muestra información como:

* **Nombre:** nombre con el que se identifica el dato.
* **Tipo de captura:** forma en que se captura la información.
* **Tipo de dato:** tipo de información que almacena.
* **Longitud:** cantidad de caracteres permitidos, cuando corresponde.
* **Decimales:** cantidad de posiciones decimales, cuando corresponde.

Los datos extraordinarios están asociados a los **Empleados**.

## Acciones disponibles

### Agregar dato extraordinario

Para agregar un dato extraordinario:

1. Selecciona el botón **Agregar** (+).
2. Selecciona la **Entidad**.
3. Captura el **Nombre** del dato.
4. Selecciona el **Tipo de captura**.
5. Captura las opciones adicionales que correspondan al tipo seleccionado.
6. Selecciona **Aceptar**.

La entidad disponible es:

* **Empleado**

Los tipos de captura disponibles son:

* **Caja de texto**
* **Caja numérica**
* **Fecha**
* **Casilla de verificación**
* **Lista desplegable**

### Configurar una caja de texto

Cuando se selecciona **Caja de texto**, se solicita la **Longitud** del dato.

### Configurar una caja numérica

Cuando se selecciona **Caja numérica**, se pueden configurar:

* **Longitud**
* **Decimales**
* **Formato**

Los formatos disponibles son:

* **Numérico**
* **Moneda**
* **Porcentaje**

### Configurar una lista desplegable

Cuando se selecciona **Lista desplegable**, se puede configurar un catálogo para las opciones disponibles.

Para utilizar opciones personalizadas:

1. Selecciona el catálogo **Personalizado**.
2. Agrega las opciones que estarán disponibles.
3. Captura el **Valor** de cada opción.
4. Captura el **Texto** que se mostrará para cada opción.
5. Utiliza la opción de eliminar para quitar una opción de la lista cuando sea necesario.

Debe existir al menos una opción personalizada cuando se utiliza esta modalidad.

### Editar dato extraordinario

Para modificar un dato extraordinario:

1. Localiza el dato que deseas modificar.
2. Selecciona el botón **Editar**.
3. Modifica la información correspondiente.
4. Selecciona **Aceptar**.

La información que puede modificarse depende del tipo de captura configurado.

### Eliminar dato extraordinario

Para eliminar un dato extraordinario:

1. Selecciona el botón **Eliminar** correspondiente.
2. Revisa el mensaje de confirmación.
3. Selecciona **Aceptar** para confirmar la eliminación.

El mensaje de confirmación muestra el **nombre del dato** y la sección a la que pertenece.

## Consideraciones

Los datos extraordinarios se muestran agrupados de acuerdo con la sección correspondiente.

El tipo de captura determina las características adicionales que pueden configurarse, como longitud, decimales, formato u opciones de selección.

El acceso a las acciones de agregar, modificar y eliminar depende de los permisos asignados al usuario.
