# Archivos

Esta pantalla permite configurar los archivos asociados a los diferentes procesos de la aplicación.

## ¿Para qué sirve?

La pantalla de **Configuración de Archivos** permite consultar los procesos disponibles y administrar los archivos que corresponden a cada uno.

Desde esta pantalla es posible:

* Consultar los procesos disponibles.
* Consultar los archivos asociados a un proceso.
* Agregar un archivo a un proceso.
* Modificar la información de un archivo.
* Eliminar un archivo.

## ¿Cómo se utiliza?

Al ingresar a la pantalla se muestran los **Procesos** disponibles.

Para consultar los archivos de un proceso:

1. Selecciona el proceso que deseas consultar.
2. Revisa los archivos asociados al proceso seleccionado.

Los datos disponibles de cada archivo son:

* **Nombre:** nombre del archivo configurado.
* **Activo:** indica si el archivo se encuentra activo.
* **Requerido:** indica si el archivo está marcado como requerido.

## Acciones disponibles

### Agregar archivo

Para agregar un archivo a un proceso:

1. Selecciona el proceso al que deseas asociar el archivo.
2. Selecciona **Agregar**.
3. Captura el **Nombre** del archivo.
4. Activa o desactiva **Activo**, según corresponda.
5. Activa o desactiva **Requerido**, según corresponda.
6. Selecciona **Guardar**.

El nombre del archivo debe ser válido y no puede registrarse nuevamente con el mismo nombre dentro del mismo proceso.

### Modificar archivo

Para modificar un archivo:

1. Selecciona el proceso correspondiente.
2. Localiza el archivo que deseas modificar.
3. Selecciona el botón **Editar**.
4. Modifica el **Nombre**, **Activo** o **Requerido**, según corresponda.
5. Selecciona **Guardar**.

### Eliminar archivo

Para eliminar un archivo:

1. Selecciona el proceso correspondiente.
2. Localiza el archivo que deseas eliminar.
3. Selecciona el botón **Eliminar**.
4. Revisa el mensaje de confirmación.
5. Selecciona **Aceptar**.

El sistema muestra el nombre del archivo antes de confirmar la eliminación.

## Consideraciones

Los archivos se administran dentro del proceso al que fueron asociados.

Las opciones para agregar, modificar o eliminar archivos dependen de los permisos asignados al usuario.
