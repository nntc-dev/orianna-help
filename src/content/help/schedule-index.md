# Turnos

Esta pantalla permite crear, editar y eliminar los turnos utilizados dentro de la organización.

> **Nota**
>
> La configuración correcta del turno es importante para el cálculo de asistencia, retardos, faltas, horas trabajadas y tiempo extraordinario.

## ¿Para qué sirve?

Sirve para definir los horarios laborales que serán asignados a los empleados dentro de ORIANNA.

Cada turno puede incluir hora de entrada, salida a comida, regreso de comida, salida de turno y sus respectivas tolerancias.

## ¿Cómo se utiliza?

Selecciona el botón **Agregar** para crear un nuevo turno, o utiliza las opciones disponibles para editar o eliminar un turno existente.

Al configurar el turno, valida cuidadosamente los horarios y tolerancias asignadas.

También puedes seleccionar un color para identificar más fácilmente el turno en distintas pantallas del sistema.

## Acciones disponibles

Desde esta pantalla puedes crear, consultar, editar o eliminar turnos.

## Consideraciones

Los turnos son utilizados por distintos procesos de T&A, por lo que cualquier cambio puede impactar el procesamiento de asistencia e incidencias.

Es recomendable validar que el turno no esté siendo utilizado en empleados, roles o plantillas antes de modificarlo o eliminarlo.
