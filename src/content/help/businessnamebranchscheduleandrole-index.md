# Relación razón social, turnos y biométricos

Esta pantalla permite relacionar cada razón social con los turnos, biométricos y plantillas de turnos que le corresponden.

> **Nota**
>
> Esta configuración es opcional. Si no se utiliza, la relación puede manejarse como todos contra todos.

## ¿Para qué sirve?

Sirve para facilitar la operación en empresas con múltiples razones sociales, limitando o filtrando los elementos que aplican para cada una.

Esto permite que, al trabajar con turnos, biométricos o plantillas, el sistema muestre opciones más relevantes según la razón social seleccionada.

## ¿Cómo se utiliza?

Selecciona una razón social y marca los turnos, biométricos y plantillas de turnos que estarán relacionados con ella.

Las relaciones configuradas ayudarán a simplificar filtros y procesos dentro de ORIANNA.

## Acciones disponibles

Desde esta pantalla puedes consultar razones sociales y administrar sus relaciones con turnos, biométricos y plantillas de turnos.

## Consideraciones

Es recomendable utilizar esta configuración cuando el cliente maneja varias razones sociales y cada una opera con diferentes turnos, dispositivos o plantillas.

Una configuración incorrecta puede provocar que algunos turnos, biométricos o plantillas no aparezcan disponibles en ciertos procesos.
