# Sincronizar con nómina

Esta pantalla permite consultar y enviar al ERP de nómina las incidencias generadas en ORIANNA.

> **Nota**
>
> Solo deben enviarse incidencias previamente generadas y autorizadas. Una vez enviadas a nómina, no podrán enviarse nuevamente.

## ¿Para qué sirve?

Sirve para sincronizar con nómina las incidencias autorizadas, como faltas, retardos, tiempo extraordinario u otros conceptos configurados para la empresa.

## ¿Cómo se utiliza?

Utiliza los filtros disponibles para consultar las incidencias por periodo, fecha, empleado, tipo de incidencia, razón social, ubicación, departamento o estatus.

Antes de sincronizar, revisa que la información mostrada sea correcta y que corresponda al periodo que se desea enviar.

## Acciones disponibles

Desde esta pantalla puedes consultar las incidencias disponibles para envío, exportar la información a **Excel** y sincronizar los registros con el ERP de nómina.

## Consideraciones

Las incidencias enviadas quedan marcadas como sincronizadas para evitar duplicidad en la integración con nómina.

Es recomendable validar el periodo, estatus e incidencias seleccionadas antes de realizar el envío.
