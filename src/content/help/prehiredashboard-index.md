# Dashboard

Esta pantalla permite consultar de forma visual y jerárquica el **headcount** de la empresa, mostrando las posiciones y su distribución de acuerdo con diferentes criterios de la estructura organizacional.

**Nota**

El Dashboard permite navegar por diferentes niveles de información para consultar el headcount de manera detallada. La información mostrada está sujeta a los permisos que tenga asignados el usuario.

## ¿Para qué sirve?

Sirve para consultar la distribución de las posiciones de la empresa y conocer el estado del headcount de acuerdo con la estructura organizacional.

La información puede consultarse de forma jerárquica utilizando diferentes niveles, como **Razón Social**, **Centro de costos**, **Departamento**, **Puesto** y **Ubicación**.

Desde esta pantalla también es posible consultar el detalle de las posiciones que forman parte de cada nivel del headcount.

## ¿Cómo se utiliza?

Al ingresar al Dashboard se muestra inicialmente la información agrupada por **Razón Social**.

Puedes seleccionar un nivel de la estructura para consultar información más detallada. De acuerdo con la navegación realizada, el sistema muestra una ruta de navegación que permite regresar a niveles anteriores.

Los niveles disponibles para la navegación pueden incluir:

* **Razón Social**
* **Centro de costos**
* **Departamento**
* **Puesto**
* **Ubicación**

Al seleccionar un nivel, el Dashboard actualiza las tarjetas correspondientes para mostrar la información relacionada con la selección realizada.

También puedes consultar el detalle del headcount para revisar las posiciones que forman parte del resultado seleccionado.

## Acciones disponibles

Desde esta pantalla puedes consultar el headcount de forma jerárquica y navegar entre los diferentes niveles de la estructura organizacional.

También puedes consultar el **detalle de headcount**, donde se muestran las posiciones correspondientes a la selección realizada.

El detalle incluye la siguiente información:

* **Posición**
* **Razón Social**
* **Puesto**
* **Departamento**
* **Ubicación**
* **Empleado**
* **Estatus**

Los estatus de las posiciones pueden ser:

* **Vacante**
* **Ocupada**
* **Congelada**
* **Cancelada**

En el detalle también se muestran los totales de posiciones y la cantidad correspondiente a cada estatus.

La información del detalle puede exportarse a **Excel** para su revisión o análisis.

## Detalle de headcount

La consulta de detalle permite revisar las posiciones que corresponden a los filtros o niveles seleccionados en el Dashboard.

El sistema muestra un resumen con el **Total** de posiciones, así como la cantidad de posiciones **Ocupadas**, **Vacantes**, **Congeladas** y **Canceladas**.

Las posiciones congeladas y canceladas se identifican visualmente dentro del detalle para facilitar su revisión.

## Consideraciones

La exportación a **Excel** contiene el detalle de las posiciones correspondientes a la consulta realizada.
