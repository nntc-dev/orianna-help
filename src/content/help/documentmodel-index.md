# Documentos

Esta pantalla permite administrar **documentos** y sus plantillas, así como generar documentos a partir de la información disponible en el sistema.

## ¿Para qué sirve?

La pantalla de **Documentos** permite consultar las plantillas de documentos disponibles y realizar acciones sobre ellas.

Desde esta pantalla es posible:

* Consultar las plantillas de documentos.
* Crear una nueva plantilla.
* Editar el contenido de una plantilla.
* Generar un documento a partir de una plantilla.
* Eliminar una plantilla.

## ¿Cómo se utiliza?

Al ingresar a la pantalla se muestra una tabla con las plantillas de documentos disponibles.

Los datos disponibles son:

* **Nombre:** nombre de la plantilla.
* **Proceso:** proceso al que corresponde la plantilla.
* **Tipo:** indica si la plantilla es **Libre** o de **Contrato**.

Las plantillas de tipo **Contrato** muestran además el tipo de contrato correspondiente.

## Acciones disponibles

### Agregar documento

Para crear una nueva plantilla:

1. Selecciona el botón **Agregar** (+).
2. Captura el **Nombre** del documento.
3. Selecciona el **Proceso** al que corresponde.
4. Selecciona el **Tipo** de documento.
5. Si seleccionaste **Contrato**, selecciona el **Tipo de contrato**.
6. Selecciona **Guardar**.

Los tipos de documento disponibles son:

* **Libre**
* **Contrato**

El nombre de la plantilla no puede repetirse.

### Editar documento

Para editar el contenido de una plantilla:

1. Localiza el documento que deseas modificar.
2. Selecciona la opción **Editar documento**.
3. Se abrirá el editor de documentos.
4. Revisa las **Columnas** disponibles.
5. Selecciona **Agregar** en la información que deseas incorporar a la plantilla.
6. Realiza los cambios necesarios en el documento.
7. Selecciona la opción de **Guardar** del editor.

Las columnas disponibles se encuentran organizadas en diferentes grupos, entre ellos:

* **Sistema**
* **Movimiento**
* **Configuración básica**
* **Estructura organizacional**
* **Identificación del empleado**
* **Sueldo**
* **Depósito bancario**
* **INFONAVIT**
* **Teléfono y correos**
* **Domicilio**
* **Información de nacimiento**
* **Datos personal**
* **Datos Socioeconómicos**
* **Otros**
* **Transporte**
* **Familiares**
* **Datos de Contrato**
* **Datos Complementarios**

Al agregar una columna, esta se incorpora a la plantilla como información que puede utilizarse al generar el documento.

### Generar documento

Para generar un documento a partir de una plantilla:

1. Localiza la plantilla que deseas utilizar.
2. Selecciona **Generar**.
3. Captura la información solicitada para generar el documento.
4. Selecciona **Aceptar**.
5. El documento generado se abre en una nueva ventana.

Los datos solicitados dependen del proceso asociado a la plantilla.

Los campos requeridos se identifican mediante el indicador correspondiente.

Cuando un campo corresponde a un valor numérico, se muestra con el formato numérico correspondiente.

### Eliminar documento

Para eliminar una plantilla:

1. Selecciona el botón **Eliminar** correspondiente.
2. Revisa el nombre del documento que se muestra en el mensaje de confirmación.
3. Selecciona **Aceptar** para confirmar la eliminación.

La eliminación requiere confirmación.

## Consideraciones

Las plantillas pueden ser de tipo **Libre** o **Contrato**.

Las plantillas de tipo **Contrato** requieren seleccionar un tipo de contrato al momento de crearlas.

La información disponible para insertar en una plantilla depende del proceso y de los datos disponibles para el documento.

El acceso a las acciones de agregar, modificar y eliminar depende de los permisos asignados al usuario.
