# Incidencias

Esta pantalla permite administrar las **incidencias** utilizadas por Tiempo y Asistencia para identificar y controlar diferentes situaciones relacionadas con la asistencia y las horas de trabajo.

## ¿Para qué sirve?

Sirve para consultar y administrar las incidencias que se utilizan en ORIANNA.

Desde esta pantalla puedes crear nuevas incidencias, modificar las existentes y eliminarlas cuando sea necesario.

También puedes configurar características de cada incidencia, como su tipo, forma de medición, color, comportamiento y si participa en la bolsa de horas.

## ¿Cómo se utiliza?

Consulta la tabla para revisar las incidencias disponibles y su información relacionada.

Para agregar una incidencia, selecciona **Agregar** y captura la información solicitada.

Al crear o modificar una incidencia, puedes definir su tipo, subtipo, medida y demás características de acuerdo con la forma en que deseas utilizarla.

Cuando una incidencia corresponda a la **bolsa de horas**, puedes indicar que aplique a esta y establecer su comportamiento.

También puedes configurar filtros adicionales para determinar a qué información se aplicará la incidencia.

## Acciones disponibles

Desde esta pantalla puedes consultar, agregar, modificar y eliminar incidencias.

Al modificar una incidencia puedes actualizar su configuración y los filtros adicionales relacionados.

## Consideraciones

La configuración de una incidencia determina cómo se utilizará dentro de Tiempo y Asistencia.

Es recomendable revisar la configuración antes de guardar una incidencia, especialmente cuando se utilice para la bolsa de horas o cuando tenga filtros adicionales.
