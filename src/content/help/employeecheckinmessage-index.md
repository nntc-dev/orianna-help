# Avisos

Esta pantalla permite configurar avisos o anuncios para los empleados dentro del control de accesos.

> **Importante**
>
> Esta funcionalidad aplica únicamente cuando la empresa utiliza un visor de eventos de marcajes configurado con ORIANNA.

## ¿Para qué sirve?

Sirve para mostrar mensajes informativos a los empleados al momento de interactuar con el control de accesos o visor de eventos.

Los avisos pueden utilizarse para comunicar recordatorios, mensajes operativos, instrucciones internas o información relevante para el personal.

## ¿Cómo se utiliza?

Selecciona el botón **Agregar** para crear un nuevo aviso.

Captura la información correspondiente, como título, mensaje, tipo de aviso, ícono, periodo de vigencia y destinatarios a quienes se mostrará.

## Acciones disponibles

Desde esta pantalla puedes crear, consultar, editar o desactivar avisos.

## Consideraciones

Los avisos solo se mostrarán durante el periodo configurado y para los destinatarios seleccionados.

Es recomendable validar que el aviso esté activo y que el visor de eventos se encuentre correctamente configurado.
