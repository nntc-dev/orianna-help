# Configuración de T&A

Esta pantalla permite configurar diferentes opciones que determinan el funcionamiento de **Tiempo y Asistencia**, así como establecer las incidencias que se utilizarán para registrar determinadas situaciones de asistencia.

## ¿Para qué sirve?

Sirve para establecer los parámetros generales de Tiempo y Asistencia.

Desde esta pantalla puedes configurar los niveles de autorización, los colores utilizados para identificar asistencias y vacaciones, los días del mes considerados para determinados cálculos, la zona horaria, el primer día de la semana y el uso de fotografías para geolocalización.

También permite seleccionar las incidencias que se utilizarán para identificar situaciones como ausencias, retardos, salidas anticipadas, tiempo extra y horas trabajadas.

## ¿Cómo se utiliza?

Captura o selecciona los valores correspondientes a la configuración de Tiempo y Asistencia.

En la sección de **Incidencias**, selecciona las incidencias que correspondan a cada situación que deseas identificar.

Revisa la configuración y selecciona **Guardar** para aplicar los cambios.

## Acciones disponibles

Desde esta pantalla puedes consultar y modificar la configuración de Tiempo y Asistencia.

También puedes establecer las incidencias que se utilizarán para las diferentes situaciones relacionadas con la asistencia.
