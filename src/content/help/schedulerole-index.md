# Roles de turnos

Esta pantalla permite crear y administrar roles de turnos para definir la rotación esperada de los empleados.

> **Nota**
>
> El rol de turnos es lo que se asigna al empleado para determinar su calendario laboral esperado.

## ¿Para qué sirve?

Sirve para generar roles a partir de una o varias plantillas de turnos previamente configuradas.

Los roles permiten construir rotaciones más completas, concatenando plantillas según la necesidad operativa de la empresa.

## ¿Cómo se utiliza?

Selecciona el botón **Agregar** para crear un nuevo rol de turnos.

Define el nombre del rol y agrega una o varias plantillas de turnos en el orden correspondiente.

## Acciones disponibles

Desde esta pantalla puedes crear, consultar, editar o eliminar roles de turnos.

## Consideraciones

Antes de crear un rol, es recomendable validar que las plantillas de turnos estén correctamente configuradas.

Cualquier cambio en el rol puede impactar la rotación esperada, asistencia, incidencias, retardos, faltas u horas extra de los empleados asignados.
