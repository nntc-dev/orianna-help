# Catálogo de procesos

Esta pantalla permite consultar los procesos disponibles en ORIANNA y ejecutar cada proceso de forma inmediata o programarlo para una ejecución posterior.

## ¿Para qué sirve?

Sirve para administrar la ejecución de los procesos disponibles en ORIANNA.

Desde esta pantalla se pueden ejecutar procesos en el momento, programarlos para una fecha específica o establecer una ejecución recurrente.

También permite consultar las **Calendarizaciones** y la **Bitácora** para revisar las ejecuciones realizadas.

## ¿Cómo se utiliza?

Consulta la tabla para revisar los procesos disponibles y su información relacionada.

Selecciona **Calendarizar / Ejecutar** en el proceso que deseas ejecutar o programar.

Al configurar la ejecución, puedes seleccionar si deseas ejecutarla ahora, una sola vez o de forma recurrente.

Cuando la ejecución sea recurrente, puedes establecer la frecuencia y los datos correspondientes a la programación.

Algunos procesos pueden solicitar parámetros adicionales antes de ejecutarse.

## Acciones disponibles

Desde esta pantalla puedes ejecutar procesos, programarlos, consultar sus calendarizaciones y revisar la bitácora de ejecuciones.

En **Calendarizaciones** puedes consultar las ejecuciones programadas y eliminar una calendarización cuando sea necesario.

En **Bitácora** puedes revisar el resultado de las ejecuciones y consultar el detalle de cada una, incluyendo los mensajes, advertencias o errores registrados.

## Consideraciones

Los datos solicitados al programar un proceso dependen del proceso seleccionado.

Para las ejecuciones recurrentes, es necesario completar la información correspondiente a la frecuencia seleccionada.
