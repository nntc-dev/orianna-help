# Roles

Esta pantalla permite administrar los **roles** que se utilizan para definir el acceso de los usuarios a las diferentes funciones del sistema.

## ¿Para qué sirve?

La pantalla de **Roles** permite consultar y administrar los roles disponibles en el sistema.

Desde esta pantalla es posible:

* Consultar los roles registrados.
* Consultar cuántos usuarios tienen asignado cada rol.
* Crear un nuevo rol.
* Modificar el nombre de un rol.
* Eliminar un rol, cuando corresponda.

## ¿Cómo se utiliza?

Al ingresar a la pantalla se muestra una tabla con los roles disponibles.

Los datos disponibles son:

* **Nombre:** nombre asignado al rol.
* **Usuarios:** cantidad de usuarios que tienen asignado el rol.

La cantidad de usuarios se muestra junto al nombre de cada rol para facilitar la identificación de los roles que tienen usuarios asignados.

## Acciones disponibles

### Agregar rol

Para crear un nuevo rol:

1. Selecciona el botón **Agregar** (+).
2. Captura el **Nombre** del rol.
3. Selecciona **Guardar**.

Una vez guardado, el nuevo rol queda disponible para ser asignado a los usuarios.

### Editar rol

Para modificar el nombre de un rol:

1. Localiza el rol que deseas modificar.
2. Selecciona el botón **Editar**.
3. Modifica el **Nombre**.
4. Selecciona **Guardar**.

### Eliminar rol

Para eliminar un rol:

1. Localiza el rol que deseas eliminar.
2. Selecciona el botón **Eliminar**.
3. Revisa el mensaje de confirmación.
4. Selecciona **Eliminar** para confirmar.

Antes de realizar la eliminación, el sistema solicita confirmar que deseas eliminar el rol.

Algunos roles están protegidos y no pueden eliminarse. En estos casos, el botón **Eliminar** se muestra deshabilitado.

## Consideraciones

Los roles se utilizan para asignar el acceso correspondiente a los usuarios del sistema.

La disponibilidad de las acciones para agregar, modificar o eliminar roles depende de los permisos asignados al usuario.
