# Causas de bloqueo

Esta pantalla permite configurar las causas de bloqueo de acceso para los empleados.

> **Nota**
>
> Esta opción aplica cuando la empresa utiliza la interfaz de ORIANNA con pantallas o visores de control de accesos.

## ¿Para qué sirve?

Sirve para definir los motivos por los cuales un empleado puede tener bloqueado el acceso a las instalaciones.

La causa configurada y su mensaje podrán mostrarse en el visor cuando el empleado intente registrar un acceso.

## ¿Cómo se utiliza?

Selecciona el botón **Agregar** para crear una nueva causa de bloqueo.

Captura la información correspondiente, como nombre de la causa, mensaje a mostrar y estatus activo.

## Acciones disponibles

Desde esta pantalla puedes crear, consultar, editar o eliminar causas de bloqueo.

## Consideraciones

El mensaje configurado debe ser claro y entendible para el personal que visualizará el aviso.

Es recomendable mantener actualizado este catálogo para que los bloqueos reflejen correctamente el motivo operativo o administrativo correspondiente.
