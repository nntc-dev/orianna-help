# Campos de Adicionales de Contrato

Esta pantalla permite administrar los campos adicionales que pueden utilizarse para registrar información complementaria de los contratos.

## ¿Para qué sirve?

La pantalla de **Campos de Adicionales de Contrato** permite consultar y configurar los campos adicionales disponibles para los contratos.

Desde esta pantalla es posible:

* Consultar los campos adicionales registrados.
* Agregar un nuevo campo.
* Modificar la configuración de un campo existente.
* Definir el tipo de información que puede capturarse.
* Indicar el formato del campo.
* Establecer si el campo es requerido.
* Activar o desactivar un campo.

## ¿Cómo se utiliza?

Al ingresar a la pantalla se muestra una tabla con los campos adicionales registrados.

Los datos disponibles son:

* **Clave:** identificador del campo adicional.
* **Nombre:** nombre asignado al campo.
* **Formato:** formato configurado para el campo.
* **Tipo:** tipo de información que maneja el campo.
* **Requerido:** indica si el campo está marcado como requerido.
* **Activo:** indica si el campo se encuentra activo.

Los tipos de información disponibles son:

* **Moneda**
* **Entero**
* **Decimal**
* **Texto**
* **Fecha**
* **Lógico**

## Acciones disponibles

### Agregar campo

Para agregar un nuevo campo adicional:

1. Selecciona el botón **Agregar** (+).
2. Captura el **Nombre** del campo.
3. Selecciona el **Tipo** de información.
4. Captura el **Formato**, cuando corresponda.
5. Activa o desactiva **Activo**, según corresponda.
6. Activa o desactiva **Requerido**, según corresponda.
7. Selecciona **Guardar**.

El nombre del campo no puede registrarse nuevamente si ya existe un campo con el mismo nombre.

### Editar campo

Para modificar un campo adicional:

1. Localiza el campo que deseas modificar.
2. Selecciona el botón **Editar**.
3. Modifica el **Tipo**, **Formato**, **Activo** o **Requerido**, según corresponda.
4. Selecciona **Guardar**.

La edición se realiza desde una ventana de configuración.

## Consideraciones

Los campos adicionales pueden manejar diferentes tipos de información, de acuerdo con el tipo seleccionado.

El estado **Activo** permite identificar los campos que se encuentran habilitados.

El estado **Requerido** permite identificar los campos que están marcados como obligatorios.

El acceso a las acciones de agregar y editar depende de los permisos asignados al usuario.
