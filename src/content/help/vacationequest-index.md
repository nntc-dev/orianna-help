# Vacaciones

Esta pantalla permite consultar, capturar y administrar solicitudes de vacaciones de los empleados.

> **Nota**
>
> En esta pantalla pueden visualizarse tanto las vacaciones capturadas por el administrador como las solicitudes realizadas por los empleados desde el Kiosco.

## ¿Para qué sirve?

Sirve para registrar vacaciones de los empleados y dar seguimiento a las solicitudes enviadas para autorización.

Desde esta pantalla se puede revisar el periodo solicitado, número de días, estatus y autorizadores relacionados.

## ¿Cómo se utiliza?

Utiliza la tabla para consultar las vacaciones registradas o las solicitudes pendientes de revisión.

Para capturar vacaciones directamente, selecciona el botón **Agregar** y registra la información correspondiente del empleado, fecha inicial, fecha final y días solicitados.

## Acciones disponibles

Desde esta pantalla puedes consultar el detalle de la solicitud, cancelar vacaciones, generar el formato en **PDF** o cambiar el autorizador en caso de ser necesario.

También puedes exportar la información consultada a **Excel** para revisión o respaldo.

## Consideraciones

Las vacaciones pueden impactar el cálculo de asistencia, incidencias y reportes relacionados con nómina, dependiendo de las reglas configuradas para la empresa.

Es recomendable validar el saldo disponible del empleado antes de registrar o autorizar una solicitud.
