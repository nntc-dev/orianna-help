# Permisos por perfil

Esta pantalla permite configurar los permisos que tiene cada **rol** dentro del sistema, indicando qué acciones puede realizar sobre los diferentes módulos, grupos y opciones.

## ¿Para qué sirve?

La pantalla de **Permisos por perfil** permite controlar las acciones que los usuarios pueden realizar de acuerdo con el rol que tienen asignado.

Desde esta pantalla es posible:

* Consultar los permisos de un rol.
* Seleccionar un módulo, grupo u opción para consultar sus permisos.
* Permitir o denegar acciones específicas.
* Permitir o denegar todos los permisos de un módulo.
* Permitir o denegar todos los permisos de una opción.
* Permitir o denegar todos los permisos de un grupo.
* Exportar los permisos del rol a Excel.

## ¿Cómo se utiliza?

Al ingresar a la pantalla se muestran los campos para seleccionar el **Rol**, **Módulo**, **Grupo** y **Opción**.

### Seleccionar un rol

En el campo **Rol**, selecciona el rol cuyos permisos deseas consultar o modificar.

Al seleccionar un rol, se muestran los permisos correspondientes a ese rol.

### Consultar por módulo, grupo u opción

Puedes utilizar los siguientes campos para limitar la información que se muestra:

* **Módulo:** permite consultar los permisos correspondientes a un módulo.
* **Grupo:** permite consultar los permisos de un grupo.
* **Opción:** permite consultar los permisos de una opción específica.

Los campos **Grupo** y **Opción** se actualizan de acuerdo con la selección realizada en los campos anteriores.

La información de permisos se organiza de acuerdo con el **Módulo**, **Grupo** y **Opción** seleccionados.

## Acciones disponibles

### Permitir o denegar una acción

Los permisos se muestran mediante acciones que pueden estar permitidas o denegadas.

Las acciones disponibles son:

* **Leer:** permite consultar la información.
* **Crear:** permite crear información.
* **Modificar:** permite modificar información.
* **Borrar:** permite eliminar información.

Para cambiar un permiso:

1. Localiza la **Opción** que deseas configurar.
2. Identifica la acción correspondiente.
3. Selecciona el permiso para cambiar su estado.
4. El permiso queda actualizado.

### Configurar todos los permisos de un módulo

Es posible cambiar todos los permisos correspondientes a un módulo al mismo tiempo.

Para hacerlo:

1. Localiza el **Módulo** que deseas configurar.
2. Selecciona la opción para cambiar sus permisos.
3. Revisa el mensaje de confirmación.
4. Selecciona **Guardar** para confirmar.

Al confirmar, todos los permisos del módulo se establecen como **permitidos** o **denegados**, según la acción seleccionada.

### Configurar todos los permisos de una opción

También es posible cambiar todos los permisos de una opción al mismo tiempo.

Para hacerlo:

1. Localiza la **Opción** que deseas configurar.
2. Selecciona la opción para cambiar sus permisos.
3. Revisa el mensaje de confirmación.
4. Selecciona **Guardar** para confirmar.

Al confirmar, todos los permisos de la opción se establecen como **permitidos** o **denegados**.

### Configurar todos los permisos de un grupo

Es posible cambiar todos los permisos correspondientes a un grupo.

Para hacerlo:

1. Localiza el **Grupo** que deseas configurar.
2. Selecciona la opción para cambiar sus permisos.
3. Revisa el mensaje de confirmación.
4. Selecciona **Guardar** para confirmar.

Al confirmar, todos los permisos del grupo se establecen como **permitidos** o **denegados**.

### Exportar permisos a Excel

Para consultar los permisos en un archivo de Excel:

1. Selecciona el **Rol** que deseas consultar.
2. Utiliza los campos de **Módulo**, **Grupo** u **Opción** si deseas limitar la información.
3. Selecciona el botón **Excel**.
4. El sistema genera el archivo con los permisos del rol.

El archivo incluye:

* **Módulo**
* **Grupo**
* **Opción**
* **Leer**
* **Crear**
* **Modificar**
* **Borrar**

Los permisos se muestran como **Sí** o **No**.

## Consideraciones

Los permisos se configuran para cada **rol**.

Un cambio realizado sobre un permiso puede afectar todas las acciones correspondientes al módulo, grupo u opción cuando se utiliza una configuración general.

La disponibilidad para modificar los permisos depende de los permisos asignados al usuario.
