# Procesos de validación

Esta pantalla permite consultar los **procesos de validación** disponibles y configurar los campos que participan en cada proceso.

## ¿Para qué sirve?

La pantalla de **Procesos de validación** permite revisar los procesos de validación y definir qué campos se encuentran activos para cada uno.

Desde esta pantalla es posible:

* Consultar los procesos de validación disponibles.
* Consultar los campos asociados a un proceso.
* Activar o desactivar campos de validación.
* Activar o desactivar todos los campos disponibles.
* Guardar los cambios realizados en un proceso.

## ¿Cómo se utiliza?

Al ingresar a la pantalla se muestra la lista de **Procesos** disponibles.

Cada proceso puede mostrar información adicional mediante sus indicadores:

* **Archivo:** indica que el proceso está relacionado con un archivo.
* **Datos complementarios:** indica que el proceso considera datos complementarios.

Para consultar los campos de un proceso:

1. Selecciona el proceso que deseas consultar.
2. Revisa los campos disponibles en el panel de detalle.
3. Los campos se muestran organizados por grupos.
4. Revisa cuáles campos se encuentran activos y cuáles están inactivos.

Los campos pueden mostrarse con los siguientes estados:

* **Activo:** el campo se encuentra habilitado para el proceso.
* **Inactivo:** el campo no se encuentra habilitado para el proceso.

## Acciones disponibles

### Activar o desactivar un campo

Para cambiar el estado de un campo:

1. Selecciona el proceso correspondiente.
2. Localiza el campo que deseas modificar.
3. Activa o desactiva el interruptor del campo.
4. Repite la acción para los demás campos que necesites modificar.
5. Selecciona **Guardar**.

Los campos que no pueden modificarse se muestran sin la opción para cambiar su estado.

### Activar todos los campos

Para activar todos los campos disponibles:

1. Selecciona el proceso correspondiente.
2. Selecciona el botón **Activar todos**.
3. Revisa los campos que quedaron activos.
4. Selecciona **Guardar**.

### Desactivar todos los campos

Para desactivar todos los campos disponibles:

1. Selecciona el proceso correspondiente.
2. Selecciona el botón **Desactivar todos**.
3. Revisa los campos que quedaron inactivos.
4. Selecciona **Guardar**.

### Guardar cambios

Al seleccionar **Guardar**, el sistema muestra un mensaje de confirmación:

**¿Estás seguro(a) de guardar los cambios al proceso de validación?**

Selecciona **Aceptar** para guardar los cambios o **Cancelar** para regresar sin guardarlos.

## Grupos de campos

Para los procesos relacionados con movimientos del empleado, los campos pueden organizarse en diferentes grupos:

* **Configuración básica**
* **Estructura organizacional**
* **Identificación del empleado**
* **Salario**
* **Depósito bancario**
* **Infonavit**
* **Teléfono y correo electrónico**
* **Domicilio**
* **Nacimiento**
* **Información personal**
* **Datos socioeconómicos**
* **Otros**
* **Transporte**
* **Disponibilidad**
* **Archivos**
* **Datos complementarios**
* **Puesto**

## Consideraciones

Los campos disponibles dependen del proceso de validación seleccionado.

Los cambios realizados corresponden al proceso seleccionado y deben guardarse para aplicar la nueva configuración.

El acceso a las acciones de modificación depende de los permisos asignados al usuario.
