# Licencias

Esta pantalla permite consultar las licencias utilizadas por ORIANNA y revisar su estado, vigencia e información relacionada.

## ¿Para qué sirve?

Sirve para consultar las licencias disponibles para los módulos de ORIANNA y conocer si se encuentran vigentes y válidas.

Desde esta pantalla también se pueden agregar o reemplazar licencias cuando sea necesario.

## ¿Cómo se utiliza?

Consulta la tabla para revisar las licencias disponibles y su información relacionada.

Para agregar o reemplazar una licencia, selecciona **Agregar** y carga uno o más archivos de licencia con formato **.lic**.

Después de cargar los archivos, ORIANNA muestra la información de las licencias para que puedas revisar sus datos antes de aplicarlas.

La información mostrada permite consultar el tipo de licencia, su versión, vigencia, estado y si es válida.

Si una licencia no es válida, se muestran las causas correspondientes para facilitar la revisión del problema.

## Acciones disponibles

Desde esta pantalla puedes consultar las licencias registradas y agregar o reemplazar licencias.

Al cargar una licencia, puedes revisar la información identificada antes de seleccionar **Aplicar**.

## Consideraciones

Antes de aplicar una licencia, revisa la información mostrada y verifica que sea la licencia correspondiente.

Una licencia que no sea válida no puede aplicarse.

Si una licencia presenta problemas, consulta las causas mostradas en pantalla para identificar la situación que debe revisarse.
