# Autorizaciones

Esta pantalla permite consultar las solicitudes que forman parte de los **flujos de autorización** y atender aquellas que requieren una acción del usuario.

## ¿Para qué sirve?

La pantalla de **Autorizaciones** permite consultar los flujos en los que el usuario participa y revisar el avance de las solicitudes que requieren autorización.

Desde esta pantalla es posible:

* Consultar los flujos de autorización.
* Consultar el avance de cada flujo.
* Revisar las solicitudes asociadas a un flujo.
* Identificar las solicitudes pendientes de autorización.
* Autorizar solicitudes.
* Rechazar solicitudes.
* Consultar el detalle de una solicitud, cuando se encuentre disponible.

## ¿Cómo se utiliza?

Al ingresar a la pantalla se muestra una lista de **Flujos**.

Cada flujo muestra información que permite identificar su avance, como:

* **Flujo:** nombre del proceso de autorización.
* **Fecha:** fecha correspondiente al flujo.
* **Firmadas:** porcentaje de avance de las autorizaciones realizadas.
* **Autorizadas:** cantidad de autorizaciones realizadas.
* **Rechazadas:** cantidad de solicitudes rechazadas.
* **Participantes:** usuarios relacionados con el flujo.

También se encuentra disponible el campo **Flujo**, que permite seleccionar el flujo que se desea consultar.

Al seleccionar un flujo, en el área de detalle se muestran las solicitudes relacionadas con ese proceso.

Las solicitudes se presentan agrupadas de acuerdo con el usuario que las generó.

Cada solicitud puede mostrar su estatus:

* **Pendiente:** la solicitud requiere una autorización.
* **Autorizado:** la solicitud fue autorizada.
* **Rechazado:** la solicitud fue rechazada.

## Acciones disponibles

### Consultar un flujo

Para consultar las solicitudes de un flujo:

1. Selecciona el **Flujo** que deseas consultar.
2. Selecciona el flujo en la lista.
3. Revisa las solicitudes que se muestran en el área de detalle.
4. Consulta el estatus de cada solicitud.

El detalle muestra las solicitudes correspondientes al flujo seleccionado y permite identificar cuáles requieren una acción.

### Seleccionar solicitudes

Cuando existen varias solicitudes disponibles para autorizar o rechazar, es posible seleccionar las solicitudes que deseas atender.

Para seleccionar todas las solicitudes:

1. Selecciona el botón **Seleccionar todas**.

Para quitar la selección:

1. Selecciona el botón **Deseleccionar todas**.

También puedes seleccionar las solicitudes de manera individual.

### Autorizar solicitudes

Para autorizar una o varias solicitudes:

1. Selecciona las solicitudes que deseas autorizar.
2. Selecciona **Autorizar**.
3. Revisa la información que se muestra en la ventana de confirmación.
4. Selecciona **Aceptar**.

La autorización se realiza sobre las solicitudes seleccionadas.

Cuando una solicitud requiere varios niveles de autorización, el proceso continúa con el siguiente nivel después de que se realiza la autorización correspondiente.

### Rechazar solicitudes

Para rechazar una o varias solicitudes:

1. Selecciona las solicitudes que deseas rechazar.
2. Selecciona **Rechazar**.
3. Revisa la información que se muestra en la ventana de confirmación.
4. Selecciona **Aceptar**.

Al rechazar una solicitud, el proceso correspondiente queda rechazado.

### Consultar el detalle de una solicitud

Cuando una solicitud cuenta con la opción de consulta:

1. Localiza la solicitud.
2. Selecciona la opción para **Ver detalle**.
3. Revisa la información disponible de la solicitud.
4. Cierra la ventana para regresar a las autorizaciones.

## Consideraciones

Las solicitudes que se muestran corresponden a los flujos en los que participa el usuario.

Una solicitud solo puede ser autorizada cuando corresponde al nivel de autorización que requiere la participación del usuario.

El estatus de cada solicitud permite identificar si se encuentra **Pendiente**, **Autorizada** o **Rechazada**.

Los flujos pueden corresponder a diferentes procesos de la aplicación, por lo que la información mostrada en cada solicitud puede variar.
