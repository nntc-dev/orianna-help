# Incidencias pendientes

Esta pantalla permite consultar y dar seguimiento a las **incidencias pendientes** de los empleados.

> **Nota**
>
> Las incidencias deben revisarse antes de continuar con los procesos de autorización o sincronización con nómina.

## ¿Para qué sirve?

Sirve para identificar incidencias que requieren revisión o atención, como faltas, retardos, tiempo extraordinario u otros conceptos configurados.

## ¿Cómo se utiliza?

Utiliza los filtros disponibles para localizar las incidencias por empleado, periodo, fecha, tipo de incidencia, razón social, ubicación, departamento o estatus.

Revisa la información de cada registro y realiza la acción correspondiente según el flujo configurado.

## Acciones disponibles

Desde esta pantalla puedes consultar las incidencias pendientes y dar seguimiento a los registros que requieren atención.
