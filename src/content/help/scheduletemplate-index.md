# Plantilla de turnos

Esta pantalla permite crear y administrar plantillas de turnos para definir rotaciones de trabajo.

> **Nota**
>
> Las plantillas se construyen tomando como base los turnos previamente configurados en ORIANNA.

## ¿Para qué sirve?

Sirve para armar secuencias de turnos que posteriormente podrán asignarse a los empleados como parte de su rotación laboral.

Una plantilla puede incluir días laborables, descansos y distintos turnos según la necesidad operativa de la empresa.

## ¿Cómo se utiliza?

Selecciona el botón **Agregar** para crear una nueva plantilla.

Define el nombre de la plantilla, la cantidad de días que tendrá la rotación y asigna el turno correspondiente a cada día.

## Acciones disponibles

Desde esta pantalla puedes crear, consultar, editar o eliminar plantillas de turnos.

## Consideraciones

Aunque es posible crear plantillas de cualquier número de días, se recomienda utilizar ciclos semanales, catorcenales o de 21 días cuando la rotación sea cíclica.

Es recomendable validar que los turnos utilizados estén correctamente configurados antes de armar la plantilla.
