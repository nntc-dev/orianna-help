# Bloqueo de empleados

Esta pantalla permite bloquear temporalmente el acceso de empleados desde ORIANNA.

> **Importante**
>
> Esta opción aplica únicamente cuando la empresa utiliza control de accesos integrado con ORIANNA, biométricos y dispositivos como puertas o torniquetes.

## ¿Para qué sirve?

Sirve para impedir el acceso de un empleado durante un periodo determinado, indicando el motivo y la duración del bloqueo.

## ¿Cómo se utiliza?

Selecciona al empleado que deseas bloquear y registra la información correspondiente, como motivo, fecha de inicio y fecha fin del bloqueo.

La pantalla permite consultar si el empleado se encuentra activo, bloqueado y el historial de bloqueos aplicados.

## Acciones disponibles

Desde esta pantalla puedes consultar empleados, aplicar bloqueos y revisar el historial de bloqueos registrados.

## Consideraciones

El bloqueo puede afectar el acceso físico del empleado a las instalaciones, dependiendo de la integración configurada con los dispositivos de control de acceso.

Es recomendable validar el motivo y periodo antes de aplicar el bloqueo.
