# Integración con nómina

Esta pantalla permite consultar las interacciones entre ORIANNA y el ERP de nómina configurado.

> **Nota**
>
> Esta opción aplica cuando ORIANNA se encuentra conectado con un sistema externo de nómina.

## ¿Para qué sirve?

Sirve para visualizar los procesos de integración entre ORIANNA y nómina, tanto de subida como de bajada de información.

Desde esta pantalla se pueden revisar las ejecuciones realizadas, su estatus y el resultado de cada interacción.

## ¿Cómo se utiliza?

Consulta la tabla para revisar las integraciones disponibles y su información relacionada.

Cuando la operación lo requiera, puedes ejecutar descargas manuales de información desde el ERP de nómina hacia ORIANNA.

## Acciones disponibles

Desde esta pantalla puedes consultar integraciones, revisar su estatus y ejecutar descargas manuales de información.

## Consideraciones

Las descargas manuales deben realizarse únicamente cuando sea necesario para la operación o para corregir información pendiente de sincronizar.

Es recomendable validar el resultado de la integración después de ejecutar un proceso manual.
